# Governance and Guidance

### Validation of FHIR Documents

Validation of FHIR Documents is expected to be performed before delivering a Document to the XDS-infrastructure and when retrieving it. This is important in documen exchange, since there is it is not possible to return a reciept to the system delivering the document. 

Here you can read more about [MedComs expectations for validation](https://medcomdk.github.io/MedComLandingPage/assets/documents/FHIRValidationGovernance.html#governance-for-fhir-validation-using-medcom-fhir-standards).
